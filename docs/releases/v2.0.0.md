# AnimalsDesktop Ver2 — v2.0.0

完成済みのモーションアセットをまとめた、Ver2の最初のリリースです。
公開先は [UDteach/AnimalsDesktopV2](https://github.com/UDteach/AnimalsDesktopV2) です。

## 今回の内容

- チンチラ3姿、ゴールデンハムスター、マカロニマウス（タン）、シマリス、セーブルフェレットの7姿に、新しい歩行・待機モーションを収録。
- 歩行のコマ進行を移動距離に合わせ、フレームごとの時間、表示サイズ、接地位置を反映。
- ゴールデンハムスターに新しい3コマの入力反応を追加。
- 60姿の選択、最大10匹、個体別サイズ、既存の保存設定に対応。残り53姿は従来素材です。
- 更新確認の参照先をVer2専用リポジトリへ変更。旧版からの初回移行は、このページのZIPを展開して起動してください。

## 起動

Windowsは通常 `AnimalsDesktop.exe`、Macは `AnimalsDesktop.app` を起動します。
回し車など従来のモーションを使う場合は、いったんアプリを終了してから、同梱の
`Start-Classic.cmd`（Windows）または `Start-Classic.command`（Mac）を起動してください。
クラシック起動では動物全体を従来素材で表示します。新しい7姿の回し車、採餌、毛づくろいは未収録です。

Windows x64が通常のWindows版です。32-bit環境用x86と、更新通信を含まないx64版もあります。
MacはApple SiliconまたはIntel用を選んでください（macOS 12以降）。
Windows版は未署名、Mac版はアドホック署名で公証されていません。

## 確認範囲

Goテスト・静的検査、素材の再生成と整合性、公開ページのリンク、Windows 3構成とMac 2構成のビルドをリリースCIで検証します。
Windowsでは歩行、入力反応、動物選択、サイズ変更、設定保存、旧素材と新素材の混在をローカルで確認しています。
実機Mac、物理的な混在DPI環境、全フレームの足滑りの定量評価は未完了です。
60姿すべての新アセットが完成したリリースではありません。制作途中の候補は含めていません。

ZIPと実行ファイルの照合用に `SHA256SUMS.txt` を添付しています。
素材の出典と収録範囲は [Ver2 asset provenance](https://github.com/UDteach/AnimalsDesktopV2/blob/main/docs/releases/ver2-asset-provenance.md) を参照してください。
