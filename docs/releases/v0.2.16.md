# AnimalsDesktop v0.2.16

Release date: 2026-07-27

## Changes

- Adds Sable Panda, Sable, and Albino ferrets on Windows and macOS.
- Expands the public selectable roster from 57 to 60 animals.
- Adds the three ferrets to grouped animal selection and the small-animal
  random pool.
- Keeps stable animal IDs, type-grouped pickers, and the mixed fixed/random
  Windows settings from v0.2.15.
- Keeps the transparent taskbar/Dock overlay, tray operation, keyboard
  reaction, random stroll, typing wheel, foraging, grooming, and click
  reactions working with the expanded roster.

## Runtime Scope

- Public selectable animals: 60.
- New runtime IDs: `ferret_sable_panda`, `ferret_sable`, and
  `ferret_albino`.
- Each ferret supports the current walking, idle, grooming, and click-reaction
  motions on Windows and macOS.
- Windows settings format remains version 4. macOS settings format remains
  version 4.
- Older saved selections remain compatible because animals are persisted by
  stable runtime IDs.

## Windows Trust

- The Windows packages for this release are not Authenticode-signed.
- Smart App Control, SmartScreen, or security software may warn about or block
  the downloaded executable.
- `SHA256SUMS.txt` and the `SECURITY.txt` inside each Windows ZIP provide
  integrity information, but they do not replace a trusted code signature.
