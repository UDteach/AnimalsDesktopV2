# AnimalsDesktop v0.2.15

Release date: 2026-07-04

## Changes

- Adds Windows settings for mixing fixed animals with random slots per pet.
- Lets each random slot target all animals or one animal type, such as rabbits or chinchillas.
- Lets global random mode target all animals or one animal type from both the settings UI and the tray menu.
- Keeps grouped animal menus and stable runtime variant ID persistence from v0.2.14.
- Keeps the public selectable roster at 57 animals with no new runtime assets in this release.

## Runtime Scope

- Public selectable animals: 57.
- Windows settings format: version 4.
- New Windows settings fields: per-slot fixed/random mode, per-slot random type, and global random type.
- Older settings remain compatible; missing fields default to fixed per-slot selections and all-animal random mode.
